Unity · C# · Editor tooling

Love, Diana
Hidden Objects

View on the App Store

I handled Unity development for this mobile game at Colto. Other contributors handled artwork and game design.

Generating varied rounds from a finite catalog

The round generator favors objects and variants that have appeared less often. It avoids duplicates within each target group, chooses distractors separately, and saves the round configuration for the game to load.

I also built a Unity Editor tool that extracts sprites from imported artwork and sorts them into backgrounds, objects, and collectibles using naming conventions.

Authoring levels for two game modes

Unity · Firebase · iOS & Android

Don-Ay: Pet Land

I rebuilt the Unity client and Firebase backend when I joined the project.

Updating game content selectively

I used a versioned catalog with separate entries for iOS and Android. The client compares the catalog with local versions and downloads the bundles it needs from Firebase Storage.

The backend maintains the catalog, and the client uses it to decide what to fetch on each platform.
