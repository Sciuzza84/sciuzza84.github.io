From layered artwork to playable levels

The artist placed each object against the background in layered artwork. I built a Unity Editor tool that used naming conventions to turn the imported layers into a level prefab and its data in one command, preserving the artist's layout.

Generating varied rounds from a finite catalog

I built a round generator that favors less-used objects and variants, keeps each target group free of duplicates, and selects distractors separately. It saves the resulting configuration so the game can load the same round again.
