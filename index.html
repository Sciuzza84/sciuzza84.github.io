From layered artwork to playable levels

Our artist hid each object in the scene by placing it carefully against the background. I built a Unity Editor tool that reads the named layers in a Photoshop file and preserves each object's position. With one click, it builds the level prefab and its ScriptableObject data. We could use the artist's layout directly in the game.

Generating varied rounds from a finite catalog

The round generator favors objects and variants that have appeared less often. It avoids duplicates within each target group, chooses distractors separately, and saves the round configuration for the game to load.
